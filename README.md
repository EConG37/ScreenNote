# 拾屏 ScreenNote · 0.10.2

Windows 桌面截图、滚动长图、台词拼图、选区 GIF 录制与压缩、标注、本地 OCR 编辑和截图历史工具。截图后直接复制，需要时进入编辑；多张历史截图可以一起带到 DeepSeek、ChatGPT 或豆包网页草稿，也可以导出后拖入其他软件，无需配置模型 API。

## 下载

在 [GitHub Releases](https://github.com/EConG37/ScreenNote/releases/latest) 下载，两个包内容相同，任选其一：

- **免安装版** `ScreenNote-0.10.2-portable-x64.zip`（306 MB）：解压到任意位置，双击 `ScreenNote.exe` 即可运行。截图历史保存在解压目录的 `data/history`，设置保存在 `%LOCALAPPDATA%\ScreenNote\settings.json`（与安装版共用）。不用了直接删文件夹。
- **安装包** `ScreenNote-0.10.2-Setup-x64.exe`（252 MB）：双击后按中文向导安装到 `%LOCALAPPDATA%\Programs\ScreenNote`，附带开始菜单和桌面快捷方式。

两个包都自带 .NET 桌面运行环境、中文 OCR 和中英离线翻译模型，无需另外安装 .NET 或 Python；支持 Windows 10 2004 及以上的 x64 系统。两个包都没有代码签名，Windows 可能提示「已保护你的电脑」，点「更多信息」→「仍要运行」即可。同一 Release 附带 `.sha256` 校验文件，可用 `Get-FileHash` 核对。完整说明见 [Windows 安装包](docs/windows-installer.md)。

0.10.2 去掉操作提醒弹窗和「总结」入口；发送给 AI 改用 Windows 原生复制粘贴，不再需要浏览器扩展或配对。新增选区 GIF 录制与微信小图压缩、滚动长图、多图拼贴（含逐张台词裁切）、大图查看与缩放，保留智能窗口框选和选区上方标注栏，底部工具栏保持单行。相比 0.7.2 的分发包，安装包裁掉了不参与运行的本地化资源、Python 测试与符号计算包，体积从 269 MB 降到 252 MB。

源码保存在仓库，安装包与免安装版保存在 Releases 中，不包含使用者的截图历史、设置或配对信息。

## 开始使用

解压免安装版后双击 `ScreenNote.exe`，或安装后从开始菜单启动；从源码运行时为 `output/ScreenNote/ScreenNote.exe`，需要 Windows 10/11 和 .NET 10 Desktop Runtime。

- 默认按 **Alt+A** 截图，默认优先使用拾屏。框选后可以移动或调整选区，选区内保持原色，外围变暗。浮动栏保持单行，右侧依次为红色取消、黄色编辑截屏、绿色复制截屏；复制采用实色背景并显示回车提示，取消与编辑保持轻量。按钮统一高度、圆角、悬停和焦点反馈。较窄屏幕下辅助功能显示为图标，悬停查看名称，三个主要操作保留文字。「发送给 AI」展开 DeepSeek／豆包／ChatGPT，由本次选择决定目标，并记住供后续操作使用。
- 点击「复制截屏」、按 Enter 或双击选区，直接复制截图并保留历史，编辑窗口不会弹出。点击「编辑截屏」或按 **Ctrl+E**，保留截图并打开编辑界面。点击「取消」或按 Esc 放弃本次截图。
- 已有图片正在编辑时，点击截图或使用快捷键直接开始下一次截图，不再弹出替换确认。之前的编辑内容自动保存到历史。
- 选择编辑后打开更大的工作区，直接绘画、标记或输入文字，OCR 面板按需展开。界面采用黑白、暖灰与少量柔和绿灰，矢量图标和两层工具栏保持统一。
- 截图时将鼠标悬停在浏览器、微信等程序窗口上，单击即可选中识别的窗口；拖动仍可自由框选。选好后，上方工具栏可直接画笔、箭头、直线、序号、马赛克等，按 V 返回调整选区。
- 编辑区底部提供 ＋／−、缩放比例和「放大查看」，也支持 Ctrl+滚轮缩放。大图查看窗口支持滚轮缩放、拖动平移和 Esc 返回。
- 工具栏包含画笔、箭头、直线、形状、文字、荧光笔、序号、马赛克和实色遮挡。使用「选择」移动标注，双击文字继续修改。
- Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。复制或保存图片使用当前标注后的版本。
- 点击顶部「图片 OCR」进行本地识别，直接修改文字；已有文字时打开原文字继续编辑。选中一段文字可以只整理该段。提供合并断行、删除空行、清理空格和恢复原文，文字修改可撤销。
- 点击「完成」收起编辑界面，软件继续在托盘常驻。也可以导入、拖入图片，或在图片编辑区域按 Ctrl+V 粘贴。
- 在「设置」修改快捷键、选择截图资料文件夹或开启开机自启。保存后显示结果并留在设置中，可以继续修改；点击「关闭」结束设置。需要完全退出时，从托盘菜单选择「退出拾屏」。

## 选区录制 GIF

按 **Alt+A** 像截图一样框选、移动或调整范围，然后点击浮动栏的 **录制 GIF**，也可在框选后按 **Ctrl+G**。点击「开始录制」，3 秒倒计时结束后录制这块屏幕区域及鼠标；原有截图和高亮只用于框选，不会叠到录制画面中。

点击「停止并复制」，或在录制控制条有焦点时按 Esc，生成循环播放的 GIF，并自动复制为文件。切换到支持文件粘贴的聊天窗口，按 **Ctrl+V** 即可带入。完成窗口提供首帧预览、再次复制、查看动画、另存为和打开文件夹；也可按住预览图拖入聊天窗口。不同软件对 GIF 粘贴和动画展示的支持不同，若无法直接粘贴，可拖入或选择生成的 GIF 文件。

录制采用 10 帧/秒，最长边超过 960 像素时等比例缩小，小选区保持原尺寸；到 60 秒或约 50 MB 自动结束。逐帧写入文件，避免把整段原始画面留在内存中。控制条从录制画面排除，需要 Windows 10 2004 或更新版本的本地桌面。点击「取消」或在录制中关闭控制条，会放弃本次录制；结束后关闭完成窗口会保留 GIF，仍可粘贴。

GIF 自动保存在当前截图资料文件夹下的 **recordings**，默认是 `ScreenNote.exe` 旁的 `data/recordings`。它们可在文件夹中查看，不进入静态截图编辑历史。设置中迁移资料位置时，已完成的 GIF 会与截图一起复制到新位置，原文件夹保留；未完成文件不迁移。生成与复制无需安装额外工具或配置 API。

默认勾选「录制后压缩为微信小图」，按画面变化裁切帧、合并重复帧，并逐步降低尺寸、帧率和颜色，目标为 950,000 字节以下。完整时长与原文件保留，小图单独保存；可取消勾选以保留清晰度。录制前可选「压缩已有 GIF」，结果页也可再次压缩。目标大小是便于分享的设置，不能保证微信一定按动图展示；当前客户端仍可能把粘贴的 GIF 当文件。

## 滚动截图与多图拼贴

框选页面正文后点 **滚动截图 → 开始采集**，把鼠标放回选区内向下滚动。快速滚轮会分成小步，在采集后继续，鼠标应保持在选区内；拖动滚动条或页面跳转可能超出可拼接范围。完成时点 **完成并复制**，长图自动保留到历史并打开编辑。建议避开固定导航、悬浮按钮和页脚；无法确认重叠时会清空后续滚动，提示回退；恢复连续内容后才能完成，避免导出缺段图片。只支持向下拼接，上限为 30,000 像素高或 2,400 万像素。

点击主窗口顶部 **多图拼贴**。可以先在历史中勾选多张图，也可以在拼图窗口点 **继续截图** 或 **添加图片**，每次最多 20 张，支持拖动缩略图排序，以及上移、下移和移除。默认台词模式保留第一张完整画面，后续图片仅显示底部台词；选中每张图后，在左侧拖动绿色上下边界或调整滑块，独立设置台词范围；「默认台词」作用于未单独调整的图片，「应用到全部」统一重置。可以开启「连续框选」，每张确认后自动继续，Esc 返回拼图。右侧支持原图比例预览和大图查看；调整「错位」距离即可看到效果。也支持竖向、横向与两列拼贴。结果可直接复制、保存 PNG，或点「完成并编辑」进入标注；原截图保留。

## 一级工具栏与新操作

**框选后的截图浮动栏**直接显示发送给 AI、图片 OCR、高亮选框、翻译。高亮在当前选区内直接绘制，按 F 返回调整截图边界，Ctrl+Z 撤销。OCR 直接打开文字编辑；翻译在本机识字后直接打开原文／译文对照窗口；发送直接切换到 AI 网页，操作结果只更新状态栏，不弹提醒窗口。等待 OCR 或网页传递时仍可开始下一次截图；正在传递时暂时禁用发送，独立的本地翻译仍可使用。编辑窗口与历史顶部也保留这些快捷入口。

- **高亮选框**：框内保留原色，外围柔和压暗，使用细白色圆角描边与蓝色短线强调。多个聚焦框的清晰区域合并，压暗仅叠加一次。支持删除、撤销、重做、历史恢复及图片导出，原图与标注分别保存。原荧光笔继续保留。
- **翻译**：直接在软件内显示原文与译文，默认自动选择中文／英文互译，也可手动指定方向。不打开 AI 页面，不依赖浏览器扩展或 API。编辑界面优先使用校对后的 OCR 文字；文字面板展开时可只翻译选中文字，没有文字时本地识字后翻译。历史最多选择 10 张，按时间顺序处理并优先使用每张保存的 OCR 文字。原文可修改，再点「翻译」或按 Ctrl+Enter 更新；「复制译文」复制结果。修改原文或方向会取消旧请求，关闭或点击停止会终止后台识别／翻译。原截图、标注与保存的 OCR 文字保持原状。

发送图片和文字均采用复制粘贴，无需安装扩展或配对。网站登录和附件支持由网站决定，草稿需要用户检查后发送。

## 快捷键与资料位置

在设置中点击「截图快捷键」框，然后直接按下需要的按键组合，系统按真实键盘事件记录，不用手写按键名称。按 Esc 放弃本次录入。推荐 **Alt+A**、**Alt+S**、**Ctrl+F8**，也可使用单键 **PrintScreen**；最多三个按键。录入和设置期间暂停截图，避免误触发。保存后设置继续保持打开。

默认开启「此快捷键优先使用拾屏」：普通程序即使注册了同一组合，也可由拾屏优先处理，不需要管理员权限。该优先方式只处理所选快捷键，其他按键正常交给原程序；关闭优先选项则采用普通注册，占用时保留原设置并提示。系统保留键以及其他程序更早截获的键盘事件不能保证覆盖，Win 组合和 F12 不开放。旧版自动避让产生的四键组合升级为 Alt+A，原来的短组合保留，不再增加按键数量。

截图资料默认放在 **ScreenNote.exe 所在文件夹的 `data/history`**。在「设置 → 截图资料存放位置」点击「选择文件夹」，再点击「保存设置」，现有截图、标注和 OCR 文字会自动迁移到所选文件夹下的 `history`。原资料文件夹保留作为备份，之后的修改只保存到新的当前位置。「打开当前文件夹」可以查看正在使用的历史；「恢复默认」后仍需保存设置。

**卸载时如果删除软件安装文件夹，其中默认存放的截图资料也会一起丢失。** 重要资料建议先迁移到独立文件夹或备份，再删除安装目录。新位置无法写入或迁移失败时，软件提示原因并继续使用原位置。首次升级会尝试将旧版 `%LOCALAPPDATA%\ScreenNote\history` 复制到新的资料位置，并保留旧资料。

设置保存在 `%LOCALAPPDATA%\ScreenNote\settings.json`，不随截图资料迁移。旧版留下的 `browser-pairing.json` 保留，但当前发送流程不再使用它。

## 桌面图标与离线包

0.6.1 延续已选定的「反白 SN」图标：黑色圆角底块与白色字母。桌面程序、窗口、托盘和浏览器插件采用同一套矢量源，包含适合不同显示大小的图标资源。

需要创建桌面入口时，在项目中运行 `scripts/create-desktop-shortcut.ps1`。脚本通过 Windows 实际桌面位置创建「拾屏.lnk」，使用程序自身的图标。已存在指向其他软件的同名快捷方式时会停止，避免覆盖。

构建带说明的 ZIP 分发包：

```powershell
.\scripts\build.ps1 -Package
```

默认生成 `output/ScreenNote-0.10.2-windows.zip`，包含程序、图标、中文增强 OCR、中英离线翻译模型、使用说明和创建桌面快捷方式的脚本。解压后运行 `ScreenNote.exe`，需要电脑已安装 .NET 10 Desktop Runtime，无需另装 Python。先把文件夹放到准备长期保留且可以写入的位置，再运行包内 `create-desktop-shortcut.ps1` 建立桌面入口。分发包只包含程序资源，不包含本机截图历史或配对资料。

## 历史截图与批量处理

选择复制或编辑的截图，以及导入图片，自动加入历史。历史同时保留原图、当前标注图片、可继续修改的标注及 OCR 文字修改，关闭软件后仍可重新打开编辑。

1. 点击「截图历史」，或双击托盘图标打开历史。
2. 双击历史条目，或点击「编辑」，继续修改已有标注和文字。
3. 勾选多张图片，选择 DeepSeek、ChatGPT 或豆包，点击顶部「发送给 AI」。按截图时间从早到晚带入，每张保持独立图片，使用最新保存的标注版本。
4. 使用「导出所选」把独立 PNG 保存到选定文件夹。程序打开导出文件夹后，可以多选文件一起拖入其他 AI 页面或聊天软件；是否支持多附件由目标软件决定。
5. 每张截图右侧的「删除」可删除单张；勾选多张后点击「删除所选」可批量删除。删除前确认数量，原图、标注和 OCR 文字一起删除，不能撤销。已导出的图片以及迁移时保留的原文件夹备份仍会保留。删除失败的截图显示原因并保留在历史中。

网页批量带入一次最多 **10 张、PNG 总和 12 MB**，超过后需减少选择或分批。这个限制用于网页连接；目标 AI 网站还可能有自己的数量、账号权限和上传限额。

历史保存在当前截图资料文件夹的 `history` 中，默认是安装目录下的 `data/history`。图片编辑与 OCR 修改自动保存，切换图片、继续截图、完成编辑及退出时也会保存。保存异常会显示提示，请确认保存状态后继续操作。

## 发送到 AI 网页

点击「发送给 AI」后，图片先复制到 Windows 剪贴板。程序找到所选 AI 网页的聊天输入框后，切换到浏览器并执行 Ctrl+V；没有打开该网页时使用默认浏览器打开。DeepSeek、ChatGPT 和豆包使用同一种方式，无需扩展、配对或模型 API。

- 先在网页中登录。若登录页或聊天框尚未就绪，内容会保留在剪贴板；登录后点击聊天输入框，按 **Ctrl+V** 即可。
- 自动粘贴前检查网页地址、聊天框、前台焦点及剪贴板。切换到其他程序或重新复制内容时会停止后续粘贴，避免贴错位置。
- 多图按顺序逐张复制、粘贴。软件不按聊天发送按钮。
- 「已执行粘贴」仅说明已执行键盘操作，请检查网页是否出现附件。网页附件限额、登录状态、页面变化或系统限制仍可能需要手动粘贴。

截图和历史始终保留在本机。完整说明及验证范围见 [AI 网页复制粘贴](docs/ai-bridge.md)。

## 本地 OCR

默认使用随软件提供的 **中文增强离线识别**，基于 RapidOCR 和 PP-OCRv4 模型，支持中文、英文、数字混排；小图自动放大增强，长图按重叠区域分段，保留后续内容。设置中可切换「Windows 系统识别」作为备用。识别不调用云端 API，不产生调用费用；临时图片在完成或取消后清理。

本机四组合成样本共 2,500 字符（中英混排、小字、深色、6,000 像素长图）中，新引擎字符编辑错误为 0，Windows 为 111。这仅代表这些样本，不代表所有截图都能完全正确。普通样本约 2.6–3.8 秒，长图约 34 秒；增强方式以准确度为主。识别结果仍可在软件内对照原图修改。完整结果和第三方组件说明见 [验证记录](docs/verification.md) 和 [OCR 组件](docs/ocr-components.md)。

## 开发与验证

中英离线翻译使用随软件提供的 OPUS-MT 模型与 CPU 引擎，每次最多 20,000 字符；保留段落与空行。普通短句无需等待网页加载；专有名词、歧义句和 OCR 错字仍需校对。只提供中英互译，其他语言尚未支持。模型来源、版本与版权见 [离线翻译](docs/translation.md)。

需要 .NET 10 SDK。桌面部分不依赖额外 NuGet 包；离线 OCR 的独立运行环境与模型在 `src/ScreenNote/ocr-runtime`，随构建复制。

首次从 GitHub 获取源码时，需要先取得不纳入 Git 历史的运行环境和模型：下载免安装版并解压（或安装 0.10.2 安装包后打开安装目录），把 `ocr-runtime` 和 `translation-models` 复制到 `src/ScreenNote/`，之后再执行构建。组件版本、来源和许可证见 [OCR 组件](docs/ocr-components.md) 和 [离线翻译](docs/translation.md)。

```powershell
.\scripts\build.ps1 -Test
```

程序内自检覆盖标注渲染与撤销、选区转换、文字整理、PNG 导出及本地中英文 OCR。历史、编辑切换和网页连接的独立检查在 `tests` 和 `browser-extension/tests`；具体结果见 [验证记录](docs/verification.md)。

包含实际桌面截图的检查需要可访问 Windows 桌面的会话。多屏不同缩放比例、长期托盘运行、开机自启和真实登录网页仍需用户环境验收。
