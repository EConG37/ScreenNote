# 拾屏 精简版 ScreenNote Lite · 1.2.0

Windows 桌面截图与录制工具：区域截图、标注、滚动长图、多图拼贴，以及带裁剪编辑的 GIF 与视频录制。截图后直接复制，需要时进入编辑；多张历史截图可以一起带到 DeepSeek、ChatGPT 或豆包网页草稿，也可以导出后拖入其他软件，无需配置模型 API、浏览器扩展或配对。

精简版去掉了完整版的图片 OCR 与中英离线翻译（这两项占了安装包的绝大部分体积），保留其余全部截图、标注、发送、历史、录制、拼图与滚动截图能力。安装包约 51 MB，安装目录、设置和自启项与完整版完全独立，可以同时安装。

## 下载

在 [GitHub Releases](https://github.com/EConG37/ScreenNote/releases/tag/v1.2.0-lite) 下载 1.2.0，两个包内容相同，任选其一：

- **安装包** `ScreenNoteLite-1.2.0-Setup-x64.exe`（约 51 MB）：双击后按中文向导安装到 `%LOCALAPPDATA%\Programs\ScreenNoteLite`，附带开始菜单和桌面快捷方式。
- **免安装版** `ScreenNoteLite-1.2.0-portable-x64.zip`：解压到任意位置，双击 `ScreenNoteLite.exe` 即可运行。截图历史保存在解压目录的 `data/history`，不用了直接删文件夹。

两个包都自带 .NET 桌面运行环境，无需另外安装 .NET 或 Python；支持 Windows 10 2004 及以上的 x64 系统。安装包没有代码签名，Windows 可能提示「已保护你的电脑」，点「更多信息」→「仍要运行」即可。同一 Release 附带 `.sha256` 校验文件，可用 `Get-FileHash` 核对。

## 录制 GIF 与视频

点主窗口顶部的 **录制**，在弹出的窗口里选 **录制 GIF** 或 **录制视频**。

- **GIF**：10/15/20 帧每秒三档，默认 15 帧，体积默认压到微信直发所需的 10 MB 以内，最长 60 秒。
- **视频**：Windows 自带的 H.264 编码，24/30 帧可选，默认带系统声音，也可以打开麦克风，最长 10 分钟；编码器随系统提供，不占安装包体积。

确认后像截图一样框选区域，按 **Enter** 开始，3 秒倒计时后录制这块屏幕区域及鼠标。录制中点 **停止并保存**；按 **Esc** 取消本次录制。

控制条本身不会进入画面：Windows 10 2004 或更新版本会把它排除在捕获之外，更早的系统会退化为把控制条拖到选区外。

结束后的编辑窗口可以：拖动画面里的框保留其中一块（选错了点「重新框选」，点「保留全画面」恢复）；用两条滑块去掉开头和结尾；选 GIF 或 MP4 导出，GIF 还能选帧率和是否压到 10 MB 以内。导出后 GIF 会直接放进剪贴板文件列表，在支持文件粘贴的聊天窗口按 **Ctrl+V** 带入；也可以把文件拖进聊天窗口。

GIF 导出按 1440 → 1080 → 840 → 640 → 480 的最长边逐级降档，直到满足 10 MB 目标或降到最小一档，同时保留原始帧率和完整时长（只降清晰度，不剪时长）。文件保存在当前资料文件夹下的 **recordings**，不进入静态截图编辑历史。录制对话框底部还有 **压缩已有 GIF…**，可以把现成的 GIF 压到同一个目标体积。

选区浮动栏的 **录制 GIF**（框选后按 **Ctrl+G**）与 **录制视频**（**Ctrl+R**）保留为快捷入口，跳过选择窗口直接开始，其余流程相同。

## 截图与编辑

- 默认按 **Alt+A** 截图。框选后可以移动或调整选区，选区内保持原色，外围变暗；把鼠标停在浏览器、微信等窗口上单击可直接选中该窗口。
- 选好后上方工具栏能直接画笔、箭头、直线、序号、马赛克等，按 **V** 返回调整选区；点击「复制截屏」、按 **Enter** 或双击选区直接复制并保留历史。
- 进入编辑后可绘画、标记、输入文字；工具栏包含选择、画笔、箭头、直线、形状、文字、荧光笔、高亮选框、序号、马赛克和实色遮挡。**Ctrl+Z** 撤销，**Ctrl+Y** 或 **Ctrl+Shift+Z** 重做。
- 编辑区底部提供 ＋／−、缩放比例和「放大查看」，也支持 Ctrl+滚轮缩放；大图查看窗口支持滚轮缩放、拖动平移和 Esc 返回。
- 可以导入图片、拖入图片，或在编辑区域按 **Ctrl+V** 粘贴。

## 滚动截图与多图拼贴

框选页面正文后点 **滚动截图 → 开始采集**，把鼠标放回选区内向下滚动，完成后点 **完成并复制**，长图自动保留到历史并打开编辑。只支持向下拼接，上限为 30,000 像素高或 2,400 万像素。

点击顶部 **多图拼贴**，可在历史中勾选多张图，或在拼图窗口点「继续截图」「添加图片」，每次最多 20 张，支持拖动缩略图排序。默认台词模式保留第一张完整画面、后续图片只显示底部台词，可逐张调整台词范围；也支持竖向、横向与两列拼贴。结果可复制、保存 PNG，或点「完成并编辑」进入标注。

## 发送到 AI 网页

点击「发送给 AI」后，图片先复制到 Windows 剪贴板，程序找到所选 AI 网页的聊天输入框后切换浏览器并执行 Ctrl+V；没有打开该网页时用默认浏览器打开。DeepSeek、ChatGPT 和豆包使用同一种方式，无需扩展、配对或模型 API。

先在网页中登录；若登录页或聊天框尚未就绪，内容会保留在剪贴板，登录后点输入框按 **Ctrl+V** 即可。自动粘贴前会检查网页地址、聊天框、前台焦点及剪贴板，切换到其他程序或重新复制内容时会停止后续粘贴。软件不按聊天发送按钮。

## 截图历史

选择复制或编辑的截图，以及导入图片，都会自动加入历史；历史同时保留原图、当前标注图片、可继续修改的标注，关闭软件后仍能重新打开编辑。可以勾选多张导出 PNG、批量删除，或发送到 AI 网页（网页批量带入一次最多 10 张、PNG 总和 12 MB）。

历史保存在当前截图资料文件夹的 `history` 中，默认是程序目录下的 `data/history`。在「设置 → 截图资料存放位置」可以改到独立文件夹，修改并保存后现有资料会自动迁移，原文件夹保留作为备份。

设置保存在 `%LOCALAPPDATA%\ScreenNoteLite\settings.json`，不随截图资料迁移。**卸载时如果删除软件安装文件夹，其中默认存放的截图资料也会一起丢失**，重要资料建议先迁移到独立文件夹。

## 快捷键与资料位置

在设置中点击「截图快捷键」框后直接按下需要的组合键即可，推荐 **Alt+A**、**Alt+S**、**Ctrl+F8**，也支持单键 **PrintScreen**，最多三个按键。默认开启「此快捷键优先使用拾屏」，普通程序即使注册了同一组合也可由拾屏优先处理，不需要管理员权限。

以管理员身份运行的程序（许多游戏及其反作弊组件）会拦截普通权限软件的快捷键，这是 Windows 的权限隔离机制；拾屏检测到此类程序进入前台时会提醒，可点击「以管理员身份重启拾屏」。

## 构建与验证

需要 .NET 10 SDK，桌面部分不依赖额外 NuGet 包。在 `lite` 目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1 -Test
powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1
powershell -ExecutionPolicy Bypass -File scripts\build-portable.ps1
```

`-Test` 会构建 Release 并运行程序内自检（标注渲染与撤销、选区转换、PNG 导出等）。安装包与免安装版分别输出到 `lite/output`。
