# AI 网页连接与历史截图批量带入（0.6.0 本地开发版）

拾屏本地处理截图、标注、OCR 和历史记录。本扩展把用户选择的文字或多张独立截图放进所选 AI 网页草稿，不需要配置模型 API。扩展不自动点击发送；网页本身可能在附加图片时向 AI 服务上传文件，用户检查附件后再提交问题。

## 安装或更新扩展

1. 运行拾屏。首次连接时，在设置中查看「连接 AI 网页」配对码。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`，启用开发者模式。
3. 选择「加载已解压的扩展」，选中项目的 `browser-extension` 文件夹。
4. 已经安装旧版扩展的用户点击扩展卡片的重新加载按钮，确认版本为 0.6.0；从更早版本升级时，浏览器可能要求确认 ChatGPT 与豆包的限定网站访问权限。从 0.4 或更早版本升级后，需在新版桌面工具中完成一次配对。
5. 点击扩展图标，输入桌面工具的 6 位配对码，点击「连接桌面工具」。
6. 打开并登录所需 AI 网页：[DeepSeek](https://chat.deepseek.com/)、[ChatGPT](https://chatgpt.com/) 或 [豆包](https://www.doubao.com/chat/)。安装或重新加载扩展后，刷新已经打开的 AI 标签页一次。

这里交付本地扩展文件，没有自动安装扩展、发布应用商店或修改浏览器配置。首次配对成功后，桌面设置收起配对码并显示「已配对 · 浏览器运行后自动连接」。桌面工具或浏览器重启会自动恢复连接，无需反复输码；暂时关闭其中一个不会撤销配对。

需要取消授权或更换扩展时，在桌面设置点击「断开配对并生成新配对码」，或保持桌面工具运行并点击扩展的「断开连接」。成功撤销会删除保存的授权，之后需重新配对；如果删除凭据失败，会报告失败并保留现有连接。浏览器请求收到授权失效的 401 后会清除本地凭据、停止重连，并提示重新配对。普通断网或桌面暂未启动不清除配对。

## 带入文字或多张历史截图

桌面 0.6.0 支持启动默认浏览器：发送时检查实时连接，连接不在时先保留当前任务，再通过 Windows 默认网页打开方式启动浏览器并打开所选网站。插件启动并重新认证后立即发现尚未领取的任务。已连接时由插件复用或创建所选网页，不额外调用默认浏览器。刚关闭浏览器后即使上次心跳尚未过期，也会依据实时连接状态启动浏览器。

默认浏览器需已安装并配对本扩展，否则只打开网页并显示配对或连接提示。启动失败时清理未领取任务，允许用户重试；未领取超时与已领取未确认分别提示检查扩展或检查草稿，不自动重复上传。授权保存方式不变。新版组合提示词需要重新加载 0.6.0 扩展，0.5.x 的配对保留，不需要再次输码。

0.5.0 保留 0.4 的实时通知：使用已配对的本机 WebSocket 接收新任务通知，再通过原有接口领取内容。通知不包含图片或 OCR 文字，口令在连接后的鉴权消息中发送，不放进地址栏或 URL。浏览器后台窗口与未打开 AI 页面均可接收通知，不再常规等待 30 秒定时检查。多张图片直接读取已经保存的 PNG，避免再次解码、编码。

实时连接每 20 秒交换心跳，断线自动重连；定时检查仍作后备。领取与上传保持单次，连接恢复会发现尚未领取的任务，已领取任务不会重复上传。旧版扩展不具备新的配对持久化行为，升级时应重新加载 0.5.0 并完成一次配对。网页就绪和附件确认时间与本机任务领取时间分开；实时通知不保证网页加载或附件上传立即完成。

- 编辑截图或 OCR 文字后，选择需要的 AI 网页，点击顶部「发送给 AI」或文字面板的「发送文字」。
- 打开「截图历史」，勾选多张图片，选择 DeepSeek、ChatGPT 或豆包，再点击顶部「发送给 AI」。附件使用每张截图当前保存的标注版本，按截图时间从早到晚保持独立图片，不会拼接成长图。
- 一次最多 10 张 PNG，图片总大小最多 12 MB。这是本地连接的传输限制；AI 网站自身的附件数量、账号权限和上传限额也可能限制结果。
- 扩展优先激活所选网站已经打开的标签页，没有时新建该网站标签页。桌面端选择的目标决定每次传递的去向，扩展弹窗中的目标选择只用于打开网页。
- 网页输入框已有文字时，仍会提供「追加／替换／取消」选择，30 秒未选择取消。文字不会自动发送。
- 多图上传控件支持多文件时一次放入全部独立图片；仅支持单文件时逐张放入，每张都必须在网页可见附件中确认，并且前面附件必须仍然存在。
- 只有全部预期文件名都出现在可见附件中才报告全部完成。如果只确认部分附件，会显示确认数量和未确认文件名。先检查网页已经存在的附件，再决定是否手动补传，避免重复上传。

## 功能边界与实际兼容性

- **文字编辑：** 查找可见、可编辑的聊天输入框，排除搜索框及对话框，使用原生输入控件赋值并触发输入事件，读取结果确认完整文字仍在草稿中。ChatGPT 的可编辑输入框也纳入识别。
- **图片附加：** 查找聊天输入框附近唯一的 PNG 上传入口；无法确定入口时停止。文件控件的 `files` 属性本身不算成功证据，必须在网页可见文字、图片名称或标题中观察到本次唯一文件名。确认附件可见不代表网站已完成上传或模型已经处理。
- **失败处理：** 未登录、页面结构变化、未安装扩展、配对失效或 60 秒未确认时，报告未完成。本地图片和文字保留，可复制或导出后手动上传。任务领取后不会因刷新或丢失回复自动重投。
- **响应时间：** 已连接时通过实时通知领取任务；AI 标签页可见时的每秒检查及 30 秒后台唤醒作为后备。浏览器暂停、连接中断、网页加载或上传较慢时仍可能等待，不能把本机通知耗时当作实际网页上传耗时。
- **真实登录页面仍待验收：** 2026-10-02 的公共读取中，DeepSeek 返回 403，豆包聊天入口超时；ChatGPT 公共页面能读取到登录及上传入口说明，但没有用户已登录页面的 DOM。因此这三个目标目前是已实现的页面适配候选，不能把模拟测试称为三个网站的实机通过。网页登录后应按下方步骤验收，网站变更时可能需要更新扩展。

## 本地通信与数据

- 桌面端仅监听 `127.0.0.1:18473`，使用 TCP HTTP 服务，无需安装管理员级 URL 预留。
- 操作接口接受 JSON POST，校验准确 Host、扩展 ID 与扩展 Origin。实时通知使用 `/events` WebSocket 升级请求，必须来自配对扩展的准确 Origin，并在连接后先验证令牌。没有 CORS 授权，普通网站来源与预检被拒绝。
- 配对码交换 256 位随机令牌，绑定扩展 ID。连续失败 10 次后必须重置配对码。取件、状态、确认、断开和实时通知连接都需要令牌。桌面启动时恢复同一份授权，重启不重新生成令牌。
- 桌面设置与加密配对独立保存在 `%LOCALAPPDATA%\ScreenNote`：`settings.json` 保存偏好，`browser-pairing.json` 使用当前 Windows 用户 DPAPI 加密保存令牌和扩展 ID。更换截图资料文件夹不会迁移这两项，也不会断开配对。换 Windows 用户、删除授权文件或更换扩展身份后，可能需要重新配对。
- 浏览器令牌持久保存在 `chrome.storage.local`，访问级别为 `TRUSTED_CONTEXTS`，AI 内容脚本不能直接读取。任务锁、待发送确认和状态错误仍存放 `chrome.storage.session`；浏览器重启后恢复凭据，不恢复或自动重放旧截图任务。
- 待传内容只存在桌面内存，最多一个待处理任务，60 秒过期。扩展不保存截图历史。截图、可编辑标注与 OCR 文字保存在当前资料文件夹的 `history`，默认是安装目录 `data/history`。桌面设置选择新的资料文件夹并保存后会迁移历史且保留源；删除安装文件夹会一并删除其中的默认资料，重要内容应先迁移或备份。
- 扩展不读取 Cookie、登录令牌，也不把聊天内容回传桌面。返回内容只有草稿处理状态、可见附件确认数量及状态消息。传输任务包括所选网站 ID、独立 PNG 数组及各自唯一文件名；批量成功确认必须与预期附件数量一致。
- 主机访问范围限定为 DeepSeek 聊天域名、ChatGPT 域名、豆包 `/chat/` 路径和本机。`tabs` 用于查找激活目标标签页，`storage` 用于保存配对和临时任务状态，`alarms` 用于浏览器挂起后检查。主机匹配规则无法限制本机端口，代码地址固定为 18473。
- 协议阻止普通网站取件，不以抵御已经能运行本机代码的进程为安全边界。服务不暴露到局域网。

## 验证与手动验收

自动检查：

```powershell
node --check browser-extension/service-worker.js
node --check browser-extension/content.js
node --check browser-extension/popup.js
node --test browser-extension/tests/content.test.cjs browser-extension/tests/worker.test.cjs
dotnet run --no-restore --project browser-extension/tests/BridgeHarness/BridgeHarness.csproj
```

C# 协议验收使用临时本机端口和项目内临时配对文件，不影响运行中的桌面工具或真实授权。JavaScript 测试覆盖持久配对、浏览器重启恢复、旧 session 迁移、断网保留、401 清除、撤销失败反馈，以及实时通知、心跳、重连与并发领取、多图附加和刷新不重复。C# 协议测试覆盖 Windows DPAPI 加密和恢复、桌面重启后原凭据认证、成功撤销后不恢复、保存及删除失败、密文损坏，以及原有实时通知、目标路由和批量限制。具体执行记录见 [验证记录](verification.md)，旧版记录仍保留原版本与范围。

每个目标网页分别手动验收：

1. 首次配对后分别重启桌面工具、浏览器，确认无需输码即可恢复连接；迁移截图资料文件夹后确认授权仍保留。
2. 登录后在空草稿放入中文、英文、多行文字，确认没有自动提交。
3. 已有草稿分别选择追加、替换、取消，核对原稿。
4. 从历史勾选 2～3 张不同的截图，确认独立附件数量、各自文件名和图片内容；标注后的图片应包含最新标注。
5. 观察页面实际上传状态，在网站允许的范围内提交问题，确认模型收到每张图。
6. 模拟网站只接收部分附件，确认桌面显示具体的已确认数量，而非全部完成。
7. 同时打开多个 AI 网站及同一网站多个标签页，确认仅所选目标处理一次。刷新或关闭页面后检查草稿及附件，再决定是否重试。
8. 主动断开配对后再重启，确认不会恢复已撤销授权；需要继续使用时重新配对。

目标地址依据：[DeepSeek 官方入口](https://deepseek.com/)、[ChatGPT 公共页面](https://chatgpt.com/)、[豆包官方付费服务协议中的网站地址](https://www.doubao.com/legal/ey01)。实现依据：[Chrome 扩展跨域请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[内容脚本隔离环境](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[服务工作线程生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)。

## 0.6.0 翻译和总结（历史行为）

顶部「翻译」「总结」将材料与提示词一同交给所选 AI 网页：编辑界面文字面板展开时优先使用选中文字或全文，否则使用当前标注图；历史多选使用有序独立图片。提示词和全部图片必须分别确认才显示成功。旧扩展可能只带入附件，会明确提示检查草稿并重新加载 0.6.0，不会将缺失提示词报成功。

图片上传前先确认文字草稿；已有草稿时保留追加、替换、取消选择，选择取消不会上传附件。页面结果由用户在网站查看，扩展不读取回答、不自动提交聊天、不增加 API 配置。更新已有扩展后刷新现有 AI 页面，配对保留。
