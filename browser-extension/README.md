# 拾屏的 AI 网页连接

扩展版 0.6.1，随桌面版 0.7.2 分发。先启动拾屏，在 Chrome 或 Edge 扩展管理页面加载本文件夹。已经加载旧版时点击重新加载，确认扩展版本为 0.6.1。从 0.4 或更早版本升级时，在新版桌面工具中完成一次配对，刷新已有 AI 网页标签页。图标与桌面工具统一使用黑底白字「SN」。

首次在扩展中输入桌面设置的 6 位配对码后，凭据会保留，桌面工具或浏览器重启会自动连接，不用反复输入。浏览器凭据保存在只允许可信扩展上下文访问的 `chrome.storage.local`；任务锁和待确认结果仍是临时状态。桌面凭据由当前 Windows 用户 DPAPI 加密，保存在 `%LOCALAPPDATA%\ScreenNote\browser-pairing.json`，不随截图资料迁移。旧 session 凭据存在时会尝试迁移，但 0.4 的桌面凭据未持久化，升级仍应完成一次新配对。

配对后延续 0.4 的本机实时通知领取新任务，没有打开 AI 页面也可以及时打开所选网页。连接期间每 20 秒交换轻量心跳；断线自动重连，30 秒定时检查只作后备。多图直接读取保存的 PNG，避免重新解码与编码。任务仍只领取一次，刷新或连接中断不会自动重复上传；网页打开和附件上传时间取决于目标网站。

从桌面选择 DeepSeek、ChatGPT 或豆包，可以带入文字，或者勾选多张历史截图批量附加。一次最多 10 张、PNG 总和最多 12 MB，图片保持独立。扩展只准备草稿，不自动发送。

只有每张唯一文件名都出现在网页可见附件中才报告全部完成；部分结果显示数量和缺失文件名。实际已登录页面兼容性仍需验收，网页变更可能需要更新适配。失败后先检查网页已有附件，再手动补传。

取消授权时，保持桌面工具运行，点击扩展「断开连接」，或在桌面设置点击「断开配对并生成新配对码」。成功撤销后需重新配对；断开失败会保留凭据并显示原因。授权失效返回 401 时，扩展清除保存的凭据并停止重连，提示重新配对。普通网络中断不会清除配对。

完整安装、目标选择、资料存放说明及验收步骤见 [网页连接说明](../docs/ai-bridge.md)。截图资料默认在安装目录 `data/history`，可以在桌面设置选择独立资料文件夹，迁移后保留源文件；删除安装文件夹会同时删除其中的默认资料。

## 0.6.0 翻译和总结

此节为 0.6.0 历史行为。桌面版 0.7.1 及之后的「翻译」已改为软件内离线中英互译，不调用扩展；「总结」继续使用所选 AI 网页。

顶部「翻译」「总结」将材料与提示词一同交给所选 AI 网页：编辑界面文字面板展开时优先使用选中文字或全文，否则使用当前标注图；历史多选使用有序独立图片。提示词和全部图片必须分别确认才显示成功。旧扩展可能只带入附件，会明确提示检查草稿并重新加载 0.6.0，不会将缺失提示词报成功。

图片上传前先确认文字草稿；已有草稿时保留追加、替换、取消选择，选择取消不会上传附件。页面结果由用户在网站查看，扩展不读取回答、不自动提交聊天、不增加 API 配置。更新已有扩展后刷新现有 AI 页面，配对保留。

## 0.6.1 离线连接修复

桌面工具未运行时，旧版会反复建立失败的 WebSocket，Chrome 扩展错误页会指向 `new WebSocket`。新版先通过已授权的本机状态检查，确认工具在线才建立实时连接；离线期间按间隔重试、保留配对，启动拾屏后自动恢复。只有桌面明确撤销授权（401）才清除配对。更新原扩展后点击一次重新加载，并刷新已打开的 AI 页面。
