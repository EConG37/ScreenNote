拾屏 精简版 - 免安装版

一、怎么用
1. 把整个文件夹解压到任意位置（U 盘、移动硬盘也可以）。
2. 双击 ScreenNoteLite.exe 启动。
   如果 Windows 弹出「已保护你的电脑」，点「更多信息」→「仍要运行」。
   这是因为程序没有购买代码签名证书，不是病毒提示。
3. 默认快捷键 Alt+A 截图，也可以右键托盘图标打开设置。
4. 截图、标注、发送到 AI 网页全部在本机完成，不调用模型 API。

二、和完整版的区别
- 精简版不包含 OCR 文字识别、文字工作台和离线翻译，体积更小。
- 截图、标注、高亮选框、发送给 AI、历史、GIF、拼图、滚动截图、放大查看都保留。
- 精简版使用独立的设置和自启项，可以和完整版同时安装。

三、文件放在哪
- 截图历史：这个文件夹下的 data\history（跟着文件夹走，换电脑拷整个文件夹即可）。
- 设置：%LOCALAPPDATA%\ScreenNoteLite\settings.json。

四、怎么卸载
直接删掉整个文件夹。若想连设置一起清掉，再删除 %LOCALAPPDATA%\ScreenNoteLite。

五、其他
- 不需要安装 .NET，运行环境在包里。
- 支持 Windows 10 2004 及以上的 64 位系统。
- 详细说明见 README.md 与 docs\ai-bridge.md。
