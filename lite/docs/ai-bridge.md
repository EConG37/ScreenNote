# 发送到 AI 网页 · 1.0.0

截图、编辑图片和历史多图统一使用 Windows 剪贴板和 Ctrl+V，不要求浏览器扩展或配对，不读取网页登录凭据，不调用模型 API。

## 使用

1. 选择 DeepSeek、ChatGPT 或豆包，点击「发送给 AI」。
2. 内容先复制到剪贴板；若未找到目标网页，程序打开默认浏览器。
3. 找到聊天输入框后切换到该浏览器，逐张粘贴图片。
4. 查看网页附件和草稿，手动点击网页的发送按钮。

尚未登录或未找到聊天框时，内容保留在剪贴板。登录后点击聊天输入框按 Ctrl+V，无需安装其他组件。多张图片未全部带入时，先检查已有附件，再从历史补充剩余图片；不会自动重试整批。

## 行为边界

- 原生图片剪贴板同时提供 Windows Bitmap 与 PNG 格式。每次粘贴后等待浏览器读取，再复制下一张。
- 使用 Windows 辅助功能查找浏览器地址栏及聊天框，支持 Chromium 浏览器和 Firefox；某些浏览器不提供页面辅助信息时需手动粘贴。
- 粘贴前复核目标网站、前台窗口、聊天框焦点和剪贴板序号；后续图片不会再次强制切回浏览器。焦点变化或剪贴板被替换后停止。
- 一次最多 10 张；历史入口继续限制 PNG 总量 12 MB。网站可能另有账号或附件限制。
- 状态使用「已执行粘贴」，不能据此认定网站已经完成上传；用户需要查看真实附件。
- 旧版加密配对文件保留，当前桌面程序不启动原扩展连接服务，也不使用已安装扩展。
